# Product scope

MyGeomatics is a geomatics company directory, interactive map, internship discovery surface, career opportunity directory and industry intelligence interface for Malaysia. It serves students, early-career talent, professionals, career switchers, recruiters and universities.

Version 0.3 is static and read-only. It includes live, user-initiated place searches and a moderated coordinate-proposal workflow, but no continuous tracking or automatic publication. It does not include authentication, applications, recruiter messaging, scraping, automated verification, payments or private data. Users are directed to official sources before acting.

Phase 2 and Phase 3 are architecture plans only. They are not implemented.
