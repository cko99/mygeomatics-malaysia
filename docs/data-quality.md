# Data quality

The public UI preserves verification labels and data-quality flags from the workbook. It does not upgrade a record to verified. Missing coordinates are displayed as “Map location pending verification”; locations remain searchable in the directory.

Hiring records receive presentation statuses based on source URL availability and observed-date age. Workbook “Active” labels alone are not treated as proof of a live vacancy. Low state counts are described as possible research gaps.

Unresolved records are included in the status count and generated snapshot rather than discarded. Only public organisational contacts are exposed.
